# Chương trình tín hiệu cố định

`fixed.add.xml` do build_network.py sinh sau khi đọc ánh xạ linkIndex trong mạng thật. Mỗi nút có 6 pha, chu kỳ 120 s, offset 0. File sample.sumocfg nạp chương trình fixed để thay chương trình mặc định của mạng. Xem docs/stage2-windows.md. Chưa áp dụng offset làn sóng xanh.
